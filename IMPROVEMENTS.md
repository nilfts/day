## 📊 Формулы

**Quality Score:**
```javascript
QS = (подтвержденные / всего) * 100
```

**Категории:**
- Отлично: QS >= 15%
- Хорошо: 10% <= QS < 15%
- Средне: 5% <= QS < 10%
- Плохо: QS < 5%

**Рекомендации:**
- Плохо → "Проверить качество трафика"
- Средне → "Оптимизировать посадочные страницы"
- Хорошо → "Масштабировать"
- Отлично → "Приоритетный источник"
