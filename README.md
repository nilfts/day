# Евгенич — Аналитический комплекс

## 📊 Описание

Полноценный аналитический дашборд для анализа лидов и звонков из Google Sheets.

## 🎯 Основные возможности

- **Загрузка данных** из Google Sheets в реальном времени
- **5 разделов аналитики**: Обзор, Лиды, Звонки, Источники, Сравнение
- **Гибкие фильтры** по источникам, каналам, городам, устройствам
- **Периоды**: сегодня, вчера, 7/30 дней, текущий/прошлый месяц
- **Сравнение периодов** для анализа динамики
- **Интерактивные графики** (Chart.js) — линейные, столбчатые, круговые
- **Экспорт данных** в CSV
- **Темная тема** и адаптивный дизайн

## 📁 Структура проекта

- **dashboard.html** — готовый файл для загрузки на Тильду (2130 строк)
- **part1-head-and-styles.html** — заголовок и CSS стили
- **part2-html-body.html** — HTML разметка
- **part3-javascript-core.txt** — JS: конфигурация и утилиты
- **part4-javascript-data.txt** — JS: загрузка данных и фильтры
- **part5-javascript-charts.txt** — JS: визуализация и графики
- **part6-javascript-init.txt** — JS: экспорт и инициализация
- **ИНСТРУКЦИЯ.md** — инструкция по ручной сборке

## 🚀 Быстрый старт

### Вариант 1: Готовый файл (рекомендуется)

1. Откройте файл `dashboard.html`
2. Скопируйте всё содержимое
3. Вставьте в HTML-блок на Тильде

### Вариант 2: Ручная сборка

Следуйте инструкции в файле [ИНСТРУКЦИЯ.md](ИНСТРУКЦИЯ.md)

## 🔧 Технологии

- **HTML5** — структура страницы
- **CSS3** — стили и адаптивный дизайн
- **JavaScript ES6+** — логика приложения
- **Chart.js 4.4.1** — визуализация данных
- **Google Sheets API** — источник данных

## 📈 Источник данных

Данные загружаются из Google Таблицы:
- **Лиды**: лист "Сборка Лиды сайт"
- **Звонки**: лист "Манго Телефония" (только источник "mango")

Таблица должна быть доступна по ссылке (настройка доступа "Просмотр для всех, у кого есть ссылка")
